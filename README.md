# glassy
SVG converter to liquid glass

![glassy logo](logo.png)

Convierte fácilmente archivos SVG a SVG liquid glass.  

## Posibles fuentes de error. 
Cuando subes un SVG creado con Canva solo interpreta lo que hayas diseñado con Canva, no imágenes de fondo.  
Tampoco funciona con emoticonos servidos como emoticono. Para ello debería hacer una captura de pantalla del emoji, pasarla a svg y volver a probar.  

El logotipo de Glassy ha sido generado con Glassy a partir de un diseño hecho en Canva.
